Database Concepts

Wallingford Motors CRM

Student Maxwell King Course COP 2937 Term Spring 2026

This is a database I built up week by week in Database Concepts, working through a car dealership system called Wallingford Motors. Each week added something: a new table, a new way to query the data, working toward a system that tracks customers, their contact history, salespeople, and vehicle inventory. It's more a running record of coursework than one finished project.

Schema

Five tables: Customer, Contact, Phone_Number, Salesperson, and Vehicle. A customer can have multiple contacts (visits, calls, follow-ups) and multiple phone numbers on file. Salespeople are tied to vehicles through an InventoryID.

Queries

A few representative queries from across the semester, showing the progression from basic filtering to joined, parameterized reports.

Filtering and Sorting

An early exercise in basic filtering and sorting: pull customers past a certain ID, sorted by last name in reverse order.

SELECT
    Customer.CustomerID,
    Customer.LastName,
    Customer.FirstName
FROM
    Customer
WHERE
    (((Customer.CustomerID) > 2))
ORDER BY
    Customer.LastName DESC;

Customer Contact History

A step up: join Customer to Contact to pull the full contact history, date, type, and remarks, for one specific customer, ordered chronologically.

SELECT
    Customer.LastName,
    Customer.FirstName,
    Contact.ContactDate,
    Contact.ContactType,
    Contact.Remarks
FROM
    Customer
    INNER JOIN Contact ON Customer.CustomerID = Contact.CustomerID
WHERE
    (((Customer.CustomerID) = 2))
ORDER BY
    Contact.ContactDate;

Customer Contact History, Parameterized

Same report, but turned into a parameter query. Instead of hardcoding a customer's ID into the SQL, it prompts for one at runtime, so the same query works for any customer without editing the SQL each time.

SELECT
    Customer.LastName,
    Customer.FirstName,
    Contact.ContactDate,
    Contact.ContactType,
    Contact.Remarks
FROM
    Customer
    INNER JOIN Contact ON Customer.CustomerID = Contact.CustomerID
WHERE
    (((Customer.CustomerID) = [Enter the CustomerID Number:]))
ORDER BY
    Contact.ContactDate;
